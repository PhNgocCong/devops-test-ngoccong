# Website giới thiệu bản thân

## Cách chạy

1. Mở thư mục `gioi-thieu-ban-than-html`.
2. Đặt ảnh cá nhân vào thư mục và đổi tên thành `avatar.jpg`.
3. Mở file `index.html` bằng Chrome/Edge.

## Những phần có trong website

- Trang chủ
- Giới thiệu bản thân
- Kỹ năng
- Dự án
- Thông tin liên hệ
- Responsive cho điện thoại

## Những chỗ cần sửa

Mở `index.html` và thay:
- Email
- Số điện thoại
- Facebook
- GitHub
- LinkedIn
- Ảnh `avatar.jpg`

Có thể thay đổi màu sắc, nội dung và dự án theo thông tin thực tế.
